# Mini Soundpad

Soundpad ตัวเล็ก ๆ สำหรับเล่นเสียงเข้าไมค์ตัวเอง ให้เพื่อนใน Discord ได้ยิน
เขียนด้วย TypeScript + Electron

---

## เริ่มใช้งาน

```bash
npm install
npm start          # build แล้วเปิดแอป
npm run typecheck  # ตรวจ type อย่างเดียว
npm run dist       # แพ็คเป็นไฟล์ติดตั้ง (.exe / .dmg / .AppImage)
```

## ตั้งค่าครั้งแรก (ขั้นตอนนี้สำคัญที่สุด)

เสียงจากโปรแกรมจะเข้าไมค์เองไม่ได้ ต้องมี **สายเสียงเสมือน** มาเป็นตัวกลาง
คิดง่าย ๆ ว่ามันคือสายแจ็คที่เสียบจากลำโพงปลอมตัวหนึ่ง ไปเข้าไมค์ปลอมอีกตัวหนึ่ง

1. ติดตั้งสายเสมือน
   - Windows: [VB-Cable](https://vb-audio.com/Cable/) (ฟรี) — จะได้อุปกรณ์ชื่อ `CABLE Input` กับ `CABLE Output`
   - macOS: [BlackHole 2ch](https://existential.audio/blackhole/)
2. เปิดแอปนี้ แล้วกด **เชื่อมต่อไมค์และสายเสมือน** (จะขอสิทธิ์ไมค์ครั้งแรก)
3. ในแผง *เส้นทางเสียง* ตั้งให้ครบ
   - ปลายทางที่ Discord ฟัง → `CABLE Input` (แอปจะเดาให้อัตโนมัติ)
   - หูฟังของเรา → หูฟังจริง
   - ไมค์ → ไมค์จริง
4. ใน Discord → Settings → Voice & Video
   - **Input Device** → `CABLE Output` (ไม่ใช่ไมค์จริงแล้ว)
   - ปิด **Echo Cancellation**
   - ปิด **Noise Suppression / Krisp**
   - ปิด **Automatic Gain Control**

> ⚠️ ข้อ 4 สามอันหลังสำคัญมาก ถ้าไม่ปิด Discord จะมองเสียงเอฟเฟกต์ว่าเป็น
> "เสียงรบกวนที่ไม่ใช่เสียงคน" แล้วกรองทิ้ง เพื่อนจะได้ยินแค่เสียงแหว่ง ๆ หรือไม่ได้ยินเลย

### แล้วเสียงพูดเราล่ะ

ถ้า Discord ฟังจากสายเสมือนอย่างเดียว เพื่อนจะไม่ได้ยินเสียงพูดเรา
แอปนี้เลยมีสวิตช์ **ส่งเสียงพูดเข้าสายเสมือนด้วย** — มันจะดูดเสียงจากไมค์จริง
แล้วผสมเข้าไปในสายเสมือนให้ เพื่อนจะได้ยินทั้งเสียงเราและเสียงเอฟเฟกต์พร้อมกัน
(ไม่ต้องไปลง VoiceMeeter เพิ่ม)

## สิ่งที่ทำได้

| ฟีเจอร์ | รายละเอียด |
|---|---|
| เพิ่มเสียง | กดปุ่ม หรือลากไฟล์ mp3/wav/ogg/flac/m4a มาวาง |
| คีย์ลัด | คลิกที่ปุ่มคีย์ลัดของเสียงนั้น แล้วกดปุ่มที่ต้องการ (คลิกขวา = ล้าง) |
| เปลี่ยนคีย์ | คลิกซ้ำแล้วกดปุ่มใหม่ ทับได้เลย |
| หยุดทุกเสียง | ค่าเริ่มต้น `Ctrl + Shift + X` เปลี่ยนได้ |
| สวิตช์คีย์ลัด | ปิดชั่วคราวตอนอยากพิมพ์แชทปกติ |
| เสียงต่อชิ้น | สไลเดอร์เล็ก ๆ ใต้ชื่อแต่ละเสียง |
| เปลี่ยนชื่อ | คลิกที่ชื่อแล้วพิมพ์ทับ |

การตั้งค่าทั้งหมดเก็บที่ `soundpad.json` ใน userData ของแอป
(Windows: `%APPDATA%\mini-soundpad`)

## ทำไมถึงเลือกแบบนี้

### Electron แทนเว็บธรรมดา
เว็บทำ 2 อย่างนี้ไม่ได้เลย: จับปุ่มลัดตอนที่เราอยู่ในหน้าต่างอื่น
กับอ่านไฟล์จากพาธเดิมได้ทุกครั้งที่เปิดโปรแกรม ซึ่งทั้งคู่คือหัวใจของ soundpad
Electron ให้ `globalShortcut` และ Node API มาครบ แถมยังใช้ Web Audio ของเบราว์เซอร์ได้ด้วย

### esbuild แทน webpack
โปรเจกต์แค่นี้ไม่ต้องการ config ยาว ๆ `esbuild` bundle ทั้งโปรเจกต์เสร็จในระดับ 50ms
และเราแยกหน้าที่ชัดเจน: **esbuild แปลงโค้ด, `tsc --noEmit` ตรวจ type**
ทำให้ build เร็วโดยไม่เสียความปลอดภัยของ type

### กราฟเสียงแยกสองสาย
```
ไฟล์เสียง ─▶ gain ─┐
                   ├─▶ master ─┬─▶ virtualDest ─▶ <audio> sink = CABLE Input ─▶ Discord
ไมค์จริง ─▶ micGain┘           └─▶ monitor ─▶ <audio> sink = หูฟังเรา
```
สังเกตว่า **ไมค์ไม่ได้ต่อเข้าสายหูฟัง** ตั้งใจแบบนั้น
ถ้าต่อแล้วผู้ใช้เปิดลำโพงแทนหูฟัง เสียงจะวนกลับเข้าไมค์กลายเป็นเสียงหอนทันที

### ทำไมใช้ `MediaStreamDestination` + `<audio>` แทนการ setSinkId บน AudioContext
`AudioContext.setSinkId` เพิ่งมี ยังไม่เสถียรเท่า `HTMLAudioElement.setSinkId`
ที่รองรับมาเป็นสิบปี เราเลยให้ Web Audio ทำงานผสมเสียงตามปกติ แล้วโยนผลลัพธ์
ออกเป็น MediaStream ให้ `<audio>` เป็นคนเลือกอุปกรณ์ปลายทาง ได้ทั้งความยืดหยุ่นและความเสถียร

### decode ไฟล์ล่วงหน้าเก็บไว้ในแรม
ถ้า decode ตอนกดปุ่ม จะมีดีเลย์ 50–200ms ต่อครั้ง ซึ่งพังมุกหมด
เราเลย decode เป็น `AudioBuffer` ทันทีที่เพิ่มเสียง แล้ว cache ไว้
กดปุ่มปุ๊บเสียงออกปั๊บ (mp3 30 วินาที ≈ 5 MB ในแรม รับได้สบาย)
บวกกับ `latencyHint: 'interactive'` ที่สั่งให้ Chromium เลือก buffer เล็กที่สุด

### `event.code` ไม่ใช่ `event.key` ตอนอ่านปุ่มลัด
`key` คือ "ตัวอักษรที่ได้" ซึ่งเปลี่ยนตามภาษา — สลับเป็นไทยแล้วปุ่ม C จะกลายเป็น "แ" คีย์ลัดพังทันที
`code` คือ "ตำแหน่งปุ่มบนคีย์บอร์ด" ไม่เปลี่ยนตามภาษา ใช้อันนี้จึงกดได้ทั้งไทยและอังกฤษ

### `contextIsolation: true` + `nodeIntegration: false`
renderer แตะ `fs` ไม่ได้เลย ต้องเรียกผ่านฟังก์ชันที่เราเปิดไว้ใน preload เท่านั้น
ตอนนี้อาจดูเวอร์ แต่วันไหนใส่ฟีเจอร์โหลดเสียงจากลิงก์ หรือแชร์ pack กับเพื่อน
มันจะกลายเป็นกำแพงกันโค้ดแปลกปลอมทันที ใส่ตอนนี้ต้นทุนถูกกว่ามาก

### ปุ่มเดี่ยวอย่าง `C` ใช้ได้ แต่มีข้อแลก
`globalShortcut` จอง **ทั้งระบบ** พอจอง C ไว้ เราจะพิมพ์ตัว c ที่ไหนไม่ได้เลย
แอปเลยทำสองอย่าง: ระบายปุ่มเป็นสีเหลืองเตือนว่าเป็นคีย์เสี่ยง
และมีสวิตช์ *คีย์ลัดทำงาน* ที่ท้ายจอไว้ปิดตอนจะพิมพ์แชท
ถ้าใช้จริงจังแนะนำเป็น `Ctrl+Shift+1..9` หรือปุ่ม Numpad จะสบายกว่า

### แถบเส้นทางสัญญาณด้านบน
ปัญหาที่คนติดกันมากที่สุดของ soundpad คือ "ตั้งเสร็จแล้วแต่เพื่อนไม่ได้ยิน"
แล้วไม่รู้ว่าพังตรงไหน แถบนี้จะติดไฟตามจุดที่มีสัญญาณจริง ๆ วิ่งผ่าน
เห็นปุ๊บรู้เลยว่าปัญหาอยู่ที่ฝั่งเราหรือฝั่ง Discord

## ไอเดียต่อยอด

- **ย่อลง tray + เปิดพร้อมเครื่อง** — เอาไว้ใช้จริงจะได้ไม่ต้องเปิดหน้าต่างค้าง
- **โฟลเดอร์เสียงแทนไฟล์เดี่ยว** — ชี้ทั้งโฟลเดอร์แล้ว scan อัตโนมัติ
- **จัดกลุ่มเป็นแท็บ (pack)** — เกม / มีม / เสียงเพื่อน แล้วสลับชุดคีย์ลัดตามแท็บ
- **ตัดท่อนเสียง** — เก็บ `startTime` / `endTime` ต่อเสียง ใช้ `source.start(0, start, duration)` ได้เลย ไม่ต้องแก้ไฟล์
- **ลดเสียงเพลงตอนพูด (ducking)** — ต่อ `DynamicsCompressorNode` โดยเอาสัญญาณไมค์เป็นตัวสั่ง
- **export/import pack เป็น .zip** — แชร์ชุดเสียงกับเพื่อนในดิสได้
